# 📝 Changelog

All notable changes to the **`godot-skills`** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-10-02

### 🎉 Initial Release - 25 Mega Skills Suite

#### 🏛️ Phase 1: Architecture & Core Foundations
- Added `godot-architecture-foundation` (Clean Architecture, Feature-First DDD, Service Locator, Health Component).
- Added `godot-typed-gdscript-mastery` (100% GDScript 2.0 Static Typing, Custom Resources, `@tool` Gizmos).
- Added `godot-event-bus-signals` (Typed Global Event Bus, Domain signal partitioning, Async callbacks).

#### ⚔️ Phase 2: Core Gameplay & Combat Mechanics
- Added `godot-character-controllers` (2D Platformer with Coyote Time, Jump Buffer & 3D Kinematic FPS/TPS).
- Added `godot-state-machine-hsm` (Hierarchical Finite State Machine with Pushdown Stack & Visual Debugger).
- Added `godot-combat-hitbox-hurtbox` (Frame-perfect Hitbox/Hurtbox layers, DamagePayload DTO, Freeze-frame Hitstop, Screen Shake).
- Added `godot-inventory-item-system` (Data-driven Slots, Auto-stacking, Equipment Manager, Weighted Loot Tables).
- Added `godot-dialogue-quest-engine` (Branching Dialogue, NPC Interactions, Quest Progression Graph & Event Bus Sync).

#### 🧠 Phase 3: AI & Procedural Generation
- Added `godot-ai-behavior-trees` (Composites, Decorators, Blackboard, Sensory Vision Cones & Alert Meters).
- Added `godot-utility-ai-goap` (Goal-Oriented Action Planning A* solver & Sigmoid Utility response curves).
- Added `godot-procedural-generation` (BSP Dungeon Generator, Cellular Automata caves, FastNoiseLite terrain biomes).
- Added `godot-navigation-server` (NavigationServer2D/3D, RVO2 Dynamic Obstacle Avoidance & Runtime NavMesh Baking).

#### 🎨 Phase 4: Graphics, Shaders & Audio
- Added `godot-shader-development` (Noise Dissolve with burn glow, 2D Outlines, 3D Toon Cel-shading, Stylized Water).
- Added `godot-vfx-particles` (GPUParticles2D/3D, Sub-emitters, Auto-cleaning Spawner, Impact VFX Pooling).
- Added `godot-audio-engine` (Audio Buses routing layout, BGM Tween Crossfader Director, SFX Sound Pool).

#### 🖥️ Phase 5: UI/UX & Data Persistence
- Added `godot-ui-ux-design-system` (Responsive Layouts, Gamepad/Keyboard Focus Navigation, Neobrutalism Button Widget).
- Added `godot-hud-minimap-camera` (Parabolic Floating Damage Numbers, SubViewport Radar Minimap, Smart Dynamic Framing Camera).
- Added `godot-input-gamepad-remapping` (Runtime InputMap Rebinding, ConfigFile persistence, Action Input Buffer).
- Added `godot-save-persistence-security` (AES-256 Multi-slot Encrypted Saves, SHA-256 Anti-Tamper Checksums & Atomic write protection).
- Added `godot-sqlite-local-db` (Offline Relational SQLite Database, Versioned SQL Migrations & Batching).
- Added `godot-resource-data-tables` (Custom Resource Data Tables, O(1) Keyed Lookups & CSV-to-Resource Importers).

#### 🌐 Phase 6: Networking, Testing & CI/CD
- Added `godot-multiplayer-high-level` (Server-Authoritative High-Level Multiplayer, RPCs, Client-Side Prediction & Reconciliation).
- Added `godot-testing-gut-tdd` (Automated GUT Unit/Integration Tests, Signal Assertions & Headless CLI Test Runner).
- Added `godot-performance-profiling` (MultiMesh 50k+ Bullet Batching, Server Bypasses, Background Threaded Streaming & In-game FPS Overlay).
- Added `godot-ci-cd-export-automation` (GitHub Actions Matrix CI/CD, Headless Multi-Platform Export & Itch.io Butler Deploy).
